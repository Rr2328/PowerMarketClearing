# 电力现货市场出清仿真平台（ClearingSim）

> 东南大学《程序设计语言工程》课程设计项目>   
> 开发语言：C++17 / Qt 6 ｜ 版本控制：Git + GitHub ｜ 数据契约：V1.3（见 `docs/data-contract.md`）

## 一、项目简介

本项目是一个**电力现货市场日前出清仿真平台**，模拟电力市场中发电侧与用户侧的申报与出清全过程。平台内置三种出清机制、两种结算方式，支持新能源渗透率调节与多时段粒度，配套完整的测试对拍体系。

**核心功能：**

- **数据管理**：解析 CSV 申报数据（96 时段原生粒度长表，兼容旧窄表自动展开），内置逐项数据校验与错误提示
- **三种出清机制**：
  - *分段报价撮合*——按"高低匹配"原则逐时段撮合供需，求解统一出清价（MCP）
  - *SCUC 机组组合*——基于 HiGHS 求解器的混合整数规划，输出机组启停计划与出力安排（含启停成本、启停甘特图可视化）
  - *二次曲线成本出清*——以二次成本函数 C(P)=aP²+bP+c 描述机组报价，求解平滑供需曲线交点
- **两种结算方式**：统一边际出清价（MCP）与按报价结算（PAB）对比（SCUC / 二次曲线模式恒为统一边际价）
- **渗透率模拟**：新能源渗透率 0–100% 可调（默认 20%），P_re(t)=渗透率×负荷(t)，观察稀缺定价触发（出清价封顶 1500 元/MWh）
- **结果可视化**：供需曲线、出清电价曲线（24/96 时段双粒度）、结算明细表、UC 启停甘特图、稀缺时段标注
- **数据导出**：出清结果、结算明细、UC 启停计划一键导出 CSV

## 二、功能模块

| 模块    | 内容                                                                              | 代码位置                                                |
| ----- | ------------------------------------------------------------------------------- | --------------------------------------------------- |
| 数据模块  | CSV 解析（csv_utils）、数据校验（data_validator）、申报读取（data_reader）、场景管理（scenario_manager） | `ClearingSim/data/`                                 |
| 算法模块  | 撮合与结算引擎（clearing_engine）、二次曲线出清（quadratic_clearing）                             | `ClearingSim/engine/`                               |
| 求解模块  | SCUC 机组组合求解器（调用 HiGHS）                                                          | `ClearingSim/uc/`                                   |
| 架构与界面 | 外观层模式分派（ClearingFacade）、Qt 主界面、Qt Charts 可视化、结果导出                               | `ClearingSim/core/`、`main.cpp`、`mainwindow.{h,cpp}` |

## 三、技术栈

- **语言**：C++17
- **界面框架**：Qt 6.5+ / Qt Widgets / Qt Charts（开发实测 Qt 6.8.3 MinGW）
- **构建系统**：CMake ≥ 3.19，测试框架 CTest（8 个测试套，含端到端集成测试）
- **数据格式**：CSV（UTF-8 带 BOM），格式约定见《数据契约 V1.3》

## 三·五、第三方依赖

| 依赖                                          | 版本      | 许可证 | 引入方式                                 | 用途                            |
| ------------------------------------------- | ------- | --- | ------------------------------------ | ----------------------------- |
| [HiGHS](https://github.com/ERGO-Code/HiGHS) | v1.15.1 | MIT | 源码直接放入 `third_party/HiGHS`（vendored） | 线性/混合整数规划求解器，用于 SCUC 机组组合出清模式 |

> 说明：`third_party/HiGHS` 为第三方开源库的快照拷贝，**非本组成员编写的代码**，不计入各成员的 git 使用记录；CMake 通过 `add_subdirectory` 直接编译为静态库，克隆仓库后无需额外步骤即可离线构建。

## 四、目录结构

```
├── ClearingSim/              # 源代码
│   ├── main.cpp / mainwindow.{h,cpp}   # 程序入口与 Qt 主窗口
│   ├── core/                 # 外观层：ClearingFacade（模式分派/结果聚合）、会话、视图
│   ├── data/                 # 数据链：data_reader、csv_utils、data_validator、scenario_manager
│   ├── engine/               # 出清引擎：clearing_engine（撮合/结算）、quadratic_clearing（二次曲线）
│   └── uc/                   # SCUC 机组组合求解器（HiGHS 建模）
├── data/samples/             # 样例数据（benchmark 对拍锚点 / scenario 教学场景 / curves 负荷曲线）
├── docs/                     # 数据契约 V1.3、样例数据现实性对照说明
├── third_party/HiGHS/        # 第三方求解器快照
└── README.md
```

## 八、如何运行

1. 安装 [Qt 6.5+](https://www.qt.io/)（含 Qt Creator）与 CMake ≥ 3.19；
2. 克隆仓库：`git clone https://github.com/Rr2328/PowerMarketClearing.git`；
3. 使用 Qt Creator 打开 `ClearingSim/CMakeLists.txt`（HiGHS 随源码一并编译，无需额外安装）；
4. 构建运行后，点击主界面 **⚡ 一键演示** 直接体验内置基准例，或在数据导入页加载 `data/samples/scenario/` 下的教学场景数据。

样例数据的生成逻辑与预期出清结果见 `data/samples/README.md`；数据格式细节见 `docs/data-contract.md`。
