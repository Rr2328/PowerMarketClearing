# 电力现货市场出清仿真平台

> 东南大学《程序设计语言工程》课程设计项目  
> 开发语言：C++ / Qt | 版本控制：Git + GitHub

## 一、项目简介

本项目是一个**电力现货市场日前出清仿真平台**，模拟电力市场中发电侧与用户侧的申报与出清过程。用户导入电厂报价数据与用户需求数据后，系统按市场规则完成撮合出清，计算统一出清价与各主体结算结果，并通过可视化曲线展示出清过程。

平台核心解决的问题：

- **数据管理**：解析 CSV 申报数据（96 时段、分段报价/询价）
- **出清计算**：按"高低匹配"原则撮合供需，求解统一出清价
- **结果可视化**：绘制供需曲线、出清电价曲线（96 时段）、出清电量统计
- **结算模拟**：按边际出清价对成交主体进行结算，生成结算明细

## 二、功能模块

| 模块     | 功能                            | 对应分支                      |
| ------ | ----------------------------- | ------------------------- |
| 数据模型模块 | CSV 数据读取、电厂/用户实体类、96 时段申报数据结构 | `feature/data-model`      |
| 出清引擎模块 | 供需撮合、统一出清价计算、结算器              | `feature/clearing-engine` |
| 界面展示模块 | Qt 主界面、QChart 曲线绘制、结果导出       | `feature/ui-chart`        |

- **版本控制**：Git（Sourcetree 客户端）+ GitHub

## 八、如何运行

1. 安装 Qt 5.x 及 Qt Creator；
2. 克隆仓库：`git clone <仓库地址>`；
3. 使用 Qt Creator 打开项目文件（`.pro` 或 `CMakeLists.txt`）；
4. 编译运行，导入 `data/` 目录下的测试 CSV 数据即可体验出清仿真。
