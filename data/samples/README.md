# data/samples 样例数据说明

数据格式依据《数据契约 V1.0》（docs/）。所有 CSV 为 UTF-8 编码。

## benchmark/ 基准例（对拍锚点，数字不得改动）
- generator_bids.csv：G1 100元/40MWh、G2 250元/60MWh
- consumer_bids.csv：U1 500元/50MWh、U2 200元/50MWh
- 预期结果（真引擎 ClearMarket）：出清价 250 元/MWh，成交 50 MWh，MCP 结算 12500 元
- 用途：B 的算法、C 的界面跑此数据必须得出上述结果（对拍验证）；平台“一键演示模式”内置案例

## scenario/ 典型场景（5 火电 + 2 风电 + 1 光伏 + 3 用户）
- generator_bids.csv：火电 5 台分价递增（150~260 元/MWh，合计 590 MWh）；
  风/光申报行仅作申报表展示，**不参与撮合**（新能源出力由平台视角滑块直给）
- consumer_bids.csv：U1 500元/200MWh、U2 380元/250MWh、U3 280元/200MWh，
  合计 650 MWh = 每时段总需求（购电侧申报总量，恒定）
- 平衡锚点：650 = 火电 590 + 滑块默认 60（新能源 MW）
- 预期演示：滑块 0 → 出清价 260、成交 590、消纳 0；滑块 60 → 成交 650、消纳 60（9.2%）；
  滑块 200 → 出清价降至 230、消纳 200（30.8%）
- 用途：平台默认导入数据集、汇报演示

## curves/ 曲线数据（已退场，待迁移）
- 负荷概念已退场：每时段需求 = 购电侧申报总量（恒定），不再由负荷曲线驱动
