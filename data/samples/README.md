# data/samples 样例数据说明

数据格式依据《数据契约 V1.0》（docs/）。所有 CSV 为 UTF-8 编码。

## benchmark/ 基准例（对拍锚点，数字不得改动）
- generator_bids.csv：G1 150元/100MWh、G2 200元/100MWh
- consumer_bids.csv：U1 300元/80MWh、U2 250元/60MWh
- 预期结果：出清价 200 元/MWh，成交 140 MWh，双方结算合计 56000 元
- 用途：B 的算法、C 的界面跑此数据必须得出上述结果（对拍验证）；平台“一键演示模式”内置案例

## scenario/ 典型场景（8 机组：5 火电 + 2 风电 + 1 光伏）
- 用途：平台默认导入数据集、汇报演示
- 规则：火电分价递增、新能源报 0 价，全部通过契约五规则

## curves/ 曲线数据（96 时段连续仿真输入）
- load_curve.csv：日负荷双驼峰（凌晨低谷约 700MW，早高峰约 1050MW，晚高峰约 1100MW）
- renewable_output.csv：W1/W2 风电 20~60MW 波动；S1 光伏夜间 0、午间峰值约 50MW
- 用途：连续仿真输出 96 点出清价曲线，演示新能源压低午间电价
- 换算：实际出力 = 表中基准出力 × 渗透率系数（界面滑条 0~50%）
